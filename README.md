# 🐜 Ant Simulation

Simulación de una colonia de hormigas, desarrollada en Python con Pygame, como ejercicio práctico para observar y comprobar los conceptos del libro **"Sistemas Emergentes"** de Steven Johnson.

## 📋 Descripción

El proyecto modela el comportamiento colectivo de una colonia de hormigas, donde patrones complejos de organización (como la búsqueda de comida o la formación de rutas) emergen a partir de reglas simples aplicadas a cada agente individual, sin un control centralizado.

## 🛠️ Tecnologías

- **Lenguaje**: Python
- **Librería gráfica**: [Pygame](https://www.pygame.org/)

## 🚀 Cómo correr el proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/angelcabra2000-droid/ant-simulation.git
   cd ant-simulation
   ```
2. Instala las dependencias:
   ```bash
   pip install pygame
   ```
3. Ejecuta la simulación:
   ```bash
   python main.py
   ```

## 📚 Referencia

Inspirado en los conceptos de sistemas emergentes y comportamiento colectivo descritos en *Sistemas Emergentes*, de Steven Johnson.
